# Custom Obsidian plugins

Plugins I wrote for my own Obsidian vault. They are built locally and copied into the vault rather than published to the community store, so each one has its own `npm run deploy` script.

## daily-carryover

Starts each new daily note as a verbatim copy of the most recent earlier daily note. I keep a longform, freeform to-do list in my daily note and prune it by hand as things stop mattering. Each day's file is left as it was, so the list's history is browsable day by day, and the plugin adds commands to step backwards and forwards through it.

See [daily-carryover/README.md](daily-carryover/README.md) for behaviour, install, and development notes.
